## How to Access the Admin Panel

1. Go to your website URL and click the **ADMIN** button in the top-right corner
2. Or navigate directly to: `https://your-domain.com/login`
3. Enter your username and password
4. Click **Sign In**

## Admin Panel Features

Once logged in, you can:

### 1. **Manage Products**
- Add new products
- Edit existing products
- Delete products
- Upload product images
- Set product status (active/draft)
- Organize products by category

### 2. **Manage Categories**
- Add new categories
- Edit category names and descriptions
- Delete categories
- All categories appear in the storefront filters

### 3. **View Dashboard**
- See overview of your shop
- Monitor product statistics

## How Products Appear on the Storefront

1. **Add a Product** in the admin panel
2. **Set Status to "Active"** (important!)
3. **The product appears immediately** on the storefront
4. **All devices see the same products** in real-time

## How Categories Work

1. **Categories are managed in the admin panel**
2. **When you add a category**, it appears in the storefront filters
3. **When you delete a category**, it's removed from the storefront
4. **Products must be assigned to a category** to be filtered properly

## Changing Your Password

1. Log in to the admin panel
2. Look for a **Change Password** option (if available)
3. Enter your current password and new password
4. Save the changes

## Troubleshooting

### "Invalid username or password"
- Make sure you're using the exact username: `Bohat imported clothes`
- Check that the password is: `bhatimported@098765`
- Note: Usernames are case-sensitive

### Products not showing on storefront
- Make sure the product status is set to **"active"**
- Check that the product is assigned to a category
- Refresh the storefront page

### Categories not appearing in filters
- Make sure the category exists in the admin panel
- Add at least one product to that category
- Refresh the storefront page

## Security Tips

1. **Change your password** after first login
2. **Don't share** your login credentials
3. **Log out** when you're done managing the shop
4. **Use a strong password** if you change it
